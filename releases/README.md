### How to Install on Android
1. Download the **`ELITE_IT_arm64-v8a.apk`** file on your device.
2. Tap the downloaded file in your notification panel or Downloads folder.
3. If prompted, allow "Install from unknown sources" in settings.
4. Tap **Install** and launch **ELITE IT**.
